## 🎨 **Design System Applied**

### **Component Structure**
```

├── Left: Arrow buttons
├── Center: Action buttons
└── Right: Menu dots

Content Area
├── Question (24px, weight 500)
└── Options (16px, weight 400)

    ├── B. Option text

    └── D. Option text

├── Previous button
├── Question counter
└── Next/Finish button
```

### **State Management**
- **Default**: Gray text, transparent backgrounds
- **Selected**: Blue text for chosen option
- **Correct**: Green text for right answers
- **Wrong**: Red text for incorrect answers
- **Disabled**: Light gray text and reduced opacity
